# CourseFlow

A Chrome extension for VILNIUS TECH students to manage classes, assignments, exams, and deadlines in one place.

## Features

- Moodle and MANO integration
- Timetable and exam synchronization
- Classes, assignments, and deadline tracking
- Calendar and student dashboard
- Manual editing and deadline reminders

## Installation

1. Download `CourseFlow-v1.4.4.zip` from the [latest release](https://github.com/MahinZx/CourseFlow/releases/latest).
2. Extract the ZIP file.
3. Open `chrome://extensions` in Chrome.
4. Enable **Developer mode** and click **Load unpacked**.
5. Select the extracted folder.

## Getting Started

Open **CourseFlow → Settings** to connect and sync Moodle, MANO, exams, and timetables. You can also add or edit classes and tasks manually.

## Privacy

Study data is stored locally in Chrome. No separate account is required.
